# Миграции SQLite

Сейчас выпущенных миграций нет. Текущая версия схемы — 0.0.0.

SQL-шаги размещаются по структуре из guidelines/database_version_migration.md:
`<целевая MAJOR.MINOR.PATCH>/<уникальный ID>.sql`. Версии сравниваются численно,
шаги внутри версии сортируются по имени. ID должны быть уникальны на всём маршруте.
Каталог поставляется полностью; отсутствие каталога блокирует проверку пути обновления.
Линейный путь от 0.0.0 поддерживается; без SQL-шагов выполняется version_sync.
При ограничении совместимости будущего релиза необходимо явно добавить проверку
поддерживаемой исходной версии, прежде чем убирать старые шаги.

Формат manifest, программных миграций и зависимостей пока не утверждён. Не добавляйте
их без согласования политики. Неизвестный формат шага блокирует запуск приложения.
Каждый шаг может использовать собственные SQLite-транзакции. Независимо от них
bootstrap сохраняет backup всей БД и восстанавливает его при ошибке любого шага
или итоговой валидации. Выпущенные шаги не следует переписывать.
