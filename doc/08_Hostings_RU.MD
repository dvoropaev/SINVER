# 8. Хостинги — Hostings

[Содержание](README_RU.md) · [Назад: Роли](07_Roles_RU.MD) · [Далее: Зоны](09_Zones_RU.MD)

Вкладка **Hostings** (`/hostings`) хранит сведения о размещении серверов: название, ссылку на кабинет или сайт, дату оплаты и описание. Карточкой можно обозначить провайдера, договор, оплачиваемую группу серверов или собственную площадку.

Каждому серверу назначается не более одного хостинга. Одному хостингу могут принадлежать несколько серверов. SINVER хранит введённые сведения; оплаты и доступность площадки он не проверяет.

## 8.1. Поля хостинга

| Поле интерфейса | Обязательность | Смысл и допустимые значения |
| --- | --- | --- |
| **Name** | Обязательно для корректной карточки; форма создания требует заполнения | Уникальное название, например `Example VPS — договор 1`. Максимум 256 символов. Начальные и конечные пробелы автоматически не удаляются. |
| **URL** | Необязательно | Полный адрес сайта или кабинета, например `https://hosting.example.net/`. Браузер проверяет формат поля URL; SINVER отдельно не проверяет схему и содержимое. Максимум 1024 символа. Для внешних ссылок используйте `https://` или `http://`. |
| **Paid until** | Необязательно | Дата, до которой оплачено размещение. В браузере выбирается календарная дата, при сохранении используется формат `YYYY-MM-DD`, например `2026-12-31`. Сервер отдельно не проверяет корректность даты. |
| **Description** | Необязательно | Условия размещения, номер договора, контакты поддержки или порядок продления. Ограничение длины в схеме базы не задано. |

**Paid until относится ко всей карточке хостинга.** Все привязанные серверы показывают эту же дату. Если у серверов одного провайдера разные сроки оплаты, создайте отдельные карточки хостинга для соответствующих договоров или групп.

## 8.2. Список и поиск

| Столбец | Что показывает |
| --- | --- |
| **Name** | Название; ссылка открывает карточку. |
| **URL** | Внешняя ссылка, открывающаяся в новой вкладке; `—`, если не заполнена. |
| **servers** | Количество серверов, непосредственно назначенных этому хостингу. |
| **Paid until** | Дата оплаты либо `—`. |
| **Description** | Первые 50 символов описания. Полный текст доступен в карточке. |

| Поле поиска | Действие |
| --- | --- |
| **Name contains** | Поиск фрагмента названия. |
| **URL contains** | Поиск фрагмента URL. |
| **Paid until** | Точное совпадение даты; диапазон дат не задаётся. |
| **Description contains** | Поиск фрагмента описания. |
| **Sort by** | `name`, `url`, `paid until`, `description`; сортировка по возрастанию. По умолчанию — `name`. |

Заполненные условия поиска действуют одновременно. Нажмите **Apply** для применения или **Reset** для возврата полного списка. Общие правила поиска и особенность отображения сортировки приведены в [главе о веб-интерфейсе](03_Web_Interface_RU.MD) и [текущих проблемах](11_Current_Issues_RU.MD).

Сортировка по **paid until** позволяет просматривать сроки оплаты по порядку; карточки без даты выводятся раньше заполненных. Автоматических напоминаний и отдельного фильтра «просрочено» нет.

## 8.3. Создание, назначение и изменение

1. В **Add hosting** заполните название и необходимые дополнительные поля.
2. Нажмите **Create**.
3. Откройте карточку сервера, выберите созданную запись в **Hosting** и сохраните сервер. Либо выберите хостинг при создании нового сервера.

Для изменения хостинга откройте его по названию, нажмите **Edit**, затем **Save**; см. [общую механику интерфейса](03_Web_Interface_RU.MD). Изменение даты оплаты сразу отражается в списке всех связанных серверов.

В карточке доступны:

| Блок | Назначение |
| --- | --- |
| **Servers in this hosting** | Серверы, назначенные этой записи. Имя сервера открывает его карточку. |
| **External link** | Внешний URL; `—`, если он отсутствует. |

### Пример: два договора у одного провайдера

Создайте `Example VPS — Web` с **Paid until = 2026-12-31** и назначьте серверу `web01`. Для сервера `db-01`, оплаченного до `2027-01-31`, создайте `Example VPS — Database`.

URL у двух карточек может совпадать. Названия должны различаться. В **Servers** у каждого сервера отобразится дата соответствующей карточки, а фильтр **Hosting** позволит отдельно просмотреть каждую группу.

## 8.4. Удаление

Нажмите **Delete hosting** в карточке и подтвердите действие. **Удаляется только запись хостинга.** Серверы сохраняются, их поле **Hosting** очищается, а унаследованная дата **Paid until** исчезает из списка серверов. IP-адреса, поддомены и DNS-записи не меняются.

Перед удалением проверьте **Servers in this hosting**. При переносе площадки можно сначала назначить этим серверам другой хостинг, затем удалить прежнюю карточку.
