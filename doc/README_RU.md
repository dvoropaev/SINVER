# SINVER — руководство администратора

SINVER — веб-приложение для учёта серверов и управления их адресными записями DNS. Оно объединяет сведения о серверах, IPv4- и IPv6-адресах, поддоменах, хостингах и DNS-зонах в одном интерфейсе.

С помощью SINVER администратор может:

- вести каталог серверов и связывать их с хостингами;
- назначать роли и цвета серверам, адресам и поддоменам;
- направлять один поддомен на несколько IP-адресов;
- просматривать план изменений DNS и публиковать записи в PowerDNS через PostgreSQL;
- выгружать файл зоны для ручной установки на BIND9.

Инвентарные данные SINVER хранятся в собственной базе **SQLite**. База **PostgreSQL** используется отдельно: в ней SINVER изменяет записи PowerDNS. Добавление сервера в каталог само по себе не создаёт сервер у провайдера и не публикует DNS-записи.

> **Это MVP, версия `0.0.0`.** Приложение находится на ранней стадии разработки. В нём нет встроенной аутентификации и разграничения доступа; для удалённой работы необходим защищённый вход через NGINX. Перед использованием с действующими DNS-зонами изучите [текущие проблемы](11_Current_Issues_RU.MD) и проверьте работу на отдельной тестовой зоне.

Руководство рассчитано на читателя, который впервые работает с SINVER. Установка показана для Debian 12 и Ubuntu 24.04 с systemd. Названия полей и кнопок сохранены на английском, как в текущем интерфейсе, и сопровождаются русскими объяснениями.
